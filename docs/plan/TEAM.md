## Communication

| Channel | Used for |
|---|---|
| WhatsApp group | Daily check-in, quick questions, blockers |
| Jira board | Who does what, status of every task, estimates |
| GitHub pull requests | Code review: every PR is reviewed by another member before merging |
| Short call each evening | Review the day, plan the next one, agree on any change of scope |

Changes to scope are agreed in the evening call, then written into Jira as a
new or edited task before anyone codes them.
